Advanced options

Call the same engine from a Jupyter notebook, JupyterLab or a Python script.

import os
from geocrop.client import EngineClient

# GEOCROP_WEB_TOKEN in the notebook environment
engine = EngineClient()
job = engine.submit(["indices", "--format", "json"])
result = engine.wait(job["id"], timeout=60)
print(engine.logs(job["id"])["text"])

If the notebook runs on another machine, use a locally forwarded port. Pass the token through an environment variable.
