Napredne opcije

Unesi jednu GeoCrop komandu. Navodnici se podržavaju za putanje s razmacima.

Konzola pokreće engine komande. Shell operatori i izvršavanje proizvoljnih programa nisu podržani.

Pozovi isti engine iz Jupyter Notebooka, JupyterLaba ili Python skripte.

import os
from geocrop.client import EngineClient

# GEOCROP_WEB_TOKEN u okruženju notebooka
engine = EngineClient()
job = engine.submit(["indices", "--format", "json"])
result = engine.wait(job["id"], timeout=60)
print(engine.logs(job["id"])["text"])

Ako je notebook na drugom računaru, koristi lokalno proslijeđeni port. Token prenesi kroz varijablu okruženja.
