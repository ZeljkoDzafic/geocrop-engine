    Jupyter and Python

    Call the same engine from a notebook, JupyterLab or a script. Set GEOCROP_WEB_TOKEN in the kernel's environment — never paste it into a cell.

    from geocrop.client import EngineClient

with EngineClient() as engine:
    job = engine.submit(["quicklook", "--bbox", "19.10", "44.72", "19.16", "44.76",
                         "--start", "2023-06-01", "--end", "2023-08-31",
                         "--out", "outputs/semberija-2023"])
    engine.wait(job["id"], timeout=900)
    print(engine.logs(job["id"])["text"])

    On another machine, forward the port over SSH and pass EngineClient(base_url=...). Paths belong to the server workspace.

    HTTP API

    Every endpoint needs the Bearer token. Submitting returns a job ID right away; poll it for status, logs and files.
