From a fresh install
to your first workflow.

Start with the software demonstration. Connect your preferred interface, then prepare a study with your own inputs and evaluation design.

Find the project on GitHub

Browse the public source, read the documentation, report issues and install GeoCrop directly from the main branch.

ZeljkoDzafic / geocrop-engine ↗Browse the main branch ↗

1. Install the engine and web extra

Use Git and Python 3.10–3.12, the versions covered by the engine’s CI. A virtual environment keeps the scientific dependencies separate.

git clone https://github.com/ZeljkoDzafic/geocrop-engine.git
cd geocrop-engine
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[all,web]'

# Run a synthetic software check in a new output directory.
geocrop demo --root outputs/my-new-demo --quick

On a later terminal session, enter the repository and activate .venv again. The all extra adds the documented segmentation, STAC and Parquet dependencies; GPU/deep-learning and external cloud-mask tools remain optional.

1. Install from PowerShell

Install Git and Python 3.12 first. Calling the environment’s executables directly avoids changing PowerShell’s activation policy.

git clone https://github.com/ZeljkoDzafic/geocrop-engine.git
cd geocrop-engine
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[all,web]"
.\.venv\Scripts\geocrop.exe demo --root outputs\my-new-demo --quick

Use .\.venv\Scripts\geocrop.exe instead of geocrop in the examples below, unless the environment is activated.

02 / BROWSER & API

Start the local workspace

Choose a random access token of at least 32 characters in your password/secret manager. Set it securely in the terminal session that starts the server.

Linux / macOS token prompt
printf 'Paste your access token (32+ characters): '
read -rs GEOCROP_WEB_TOKEN
printf '\n'
export GEOCROP_WEB_TOKEN
PowerShell token prompt
$tokenInput = Read-Host 'Access token (32+ characters)' -AsSecureString
$env:GEOCROP_WEB_TOKEN = [System.Net.NetworkCredential]::new('', $tokenInput).Password
geocrop serve --workspace . --port 8765

Open http://127.0.0.1:8765 locally and enter the same token. The workspace provides forms, an engine command console, logs and output downloads. The token is not a command parameter or a value to commit.

05 / QGIS

Add the Processing provider

  1. Keep the engine web server running.
  2. Download the plugin ZIP below.
  3. In QGIS choose Plugins → Manage and Install Plugins → Install from ZIP.
  4. Enable GeoCrop Engine and QGIS’s built-in Processing plugin.
  5. Open Processing Toolbox → GeoCrop Engine.

Supply the token through QGIS’s process environment or an unlocked QGIS Basic authentication configuration, using its password field for the engine token. Run a command, try the synthetic demo or reconnect using a job ID.

What do I need for a real study?

Sentinel observations or prepared scenes, a projected analysis grid, interpreted training polygons, parcel boundaries and independent validation observations. CDSE downloads need your account credentials; Sentinel-1 GRD preprocessing needs a separate ESA SNAP installation. No satellite images, private parcel data or pretrained weights are bundled.

Where are the results?

A demo writes beneath its --root. Config-driven studies use paths.output, plus the configured composite/feature paths. Typical products include prediction/classes.tif, probabilities.tif, parcels/parcels.gpkg, validation reports and run manifests. Temporal QA is stored beside the time-series stack.

Can I use a remote server?

Yes, through a local forwarded port. The engine UI/API binds to loopback and runs as one trusted owner. Keep tokens out of source/notebook outputs. This presentation is a separate static site and does not expose an engine server.

What do the results establish?

The demo checks software integration only. Real crop accuracy, calibration coverage and review workload need an independent observational evaluation. Use the input audit, retain manifests and report the study’s sampling and threshold choices.
