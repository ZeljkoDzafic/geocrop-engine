From observation

An open, local-first engine for crop mapping and parcel verification. GeoCrop turns Copernicus time series into crop maps with probabilities, and those into parcel decisions that state their evidence.

Validation rigour

Accuracy you can defend.

Neighbouring pixels are not independent. GeoCrop evaluates with that in mind by default, and every number traces back to the split that produced it.

Spatial-block CV

Class-stratified spatial blocks, optional buffers that drop training polygons near held-out pixels, leakage assertions and nested tuning.

Locked holdout

Whole spatial blocks set aside before model selection and scored once. In holdout calibration mode the predictor stays frozen.

Transfer: LORO and LOYO

Leave-one-region-out, leave-one-year-out and region-year CV report per-group metrics and the gap to spatial-block CV.

Conformal prediction sets

Temperature-scaled probabilities and class-conditional conformal sets: an ambiguous parcel says which crops it could be.

Area of Applicability

Flags predictions in feature space the model never saw. Parcels below the AOA threshold go to review instead of being accepted.

Independent evaluation

Field points near training polygons are excluded automatically; bootstrap CIs, area-adjusted estimates and calibration error.

Public benchmark · protocol v1

EuroCrops Slovenia 2021, Pomurje

Seven crop classes, Sentinel-2 L2A, a frozen protocol file and one command to reproduce. Parcel-level scores on a spatial-block holdout with 95 % block-bootstrap intervals.

A public transfer task on farmers’ declarations, not field-verified labels, and not Republic of Srpska data. Valid for this protocol only; not evidence of accuracy elsewhere.

Parcel decisions

Every parcel says why.

Pixel probabilities are aggregated inside an interior buffer, or parcels are classified directly from their signatures. Each parcel is accepted or sent to review with stable reason codes.

  • Sentinel-2 and Sentinel-1 markers. Harvest, told apart from senescence when radar is available; tillage; dated mowing events; within-parcel homogeneity. Each with confidence and data-sufficiency fields.
  • A traffic light for Checks by Monitoring. Optional rules can only escalate a colour, and absence rules fire only on confident, sufficient data.
  • A review aid, not a verdict. A reason describes the configured rule, not a verified crop error or a legal finding.

Models and pretrained adapters

Bring in the state of the art.
Keep the same yardstick.

Every model and feature source runs behind the same spatial CV, ablation and prediction, so a new idea is compared on identical folds.

Foundation-model embeddings

An optional feature group emb from Presto, computed locally on the CPU from GeoCrop’s own composites, or from AlphaEarth and TESSERA annual embeddings. Ablation adds handcrafted, embeddings-only and combined rows.

Fields of The World boundaries

ftw-boundaries runs pretrained field-boundary models on two-window composites: CC-BY checkpoints by default, SHA-256-pinned download, watershed parcels, scored like OBIA and the U-Net.

Active learning for field campaigns

Pick a diverse, well-spaced batch among the most uncertain parcels, grouped into trips. Ingest labels with per-round provenance, and simulate label budgets against random sampling.

Classifiers and temporal networks

Random Forest, ExtraTrees, HistGradientBoosting, LightGBM, CatBoost, TempCNN and L-TAE, plus parcel-level classification on signatures, on one benchmark harness.

Heavy dependencies and checkpoints are optional and fetched at runtime; nothing is bundled. Licences and attribution: embeddings, field boundaries, active learning.

Reliability gate

Killed, then recovered

A real run is killed inside features, train and predict and must recover to the uninterrupted result. Partial outputs are quarantined; a disk guard stops before writing.

Report: acceptance-0.10-dev-2026-10-26. The acceptance checks cover the technical integrity of the chain on that area, not crop-map accuracy.

Open by architecture

One engine. Every way you work.

A layered core — local logic, adapters for networks and external programs, application, interfaces — enforced by architecture tests. Extend it through plugin registries for classifiers, indices, segmenters, exporters and validators.

The browser, on your machine

geocrop serve binds to loopback and requires a token on every API request. Jobs are queued, logged, cancellable and their outputs downloadable. Sentinel-2 cloudless and OpenStreetMap basemaps sit under the imagery.

Inside QGIS Processing

A standalone plugin adds run-command, demo and load-job algorithms to the Processing Toolbox. It talks to the engine API, streams logs, reconnects to jobs and loads results as layers. QGIS keeps its own Python.

Notebooks and scripts

EngineClient submits the same commands, polls jobs, reads logs and downloads artifacts, without putting the token in the notebook. It uses /api/v1 and falls back on older servers.

Example notebook
notebook.py
# GEOCROP_WEB_TOKEN comes from the environment.
from geocrop.client import EngineClient

with EngineClient() as engine:
    job = engine.submit(["indices", "--format", "json"])
    engine.wait(job["id"], timeout=60)
    print(engine.logs(job["id"])["text"])

A versioned REST contract

Every endpoint is served under /api/v1, the documented stable contract with an OpenAPI schema. Requests need a Bearer token; request bodies and job arguments are size-limited.

Get started

A first run in seconds.

Install, run the synthetic demo, then open the workspace. Python 3.10–3.12.

Terminal
git clone https://github.com/ZeljkoDzafic/geocrop-engine.git
cd geocrop-engine
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -e '.[all,web]'
geocrop demo --root outputs/my-first-demo --quick

# Workspace: first set GEOCROP_WEB_TOKEN (32+ random characters)
geocrop serve --workspace . --port 8765
PowerShell
git clone https://github.com/ZeljkoDzafic/geocrop-engine.git
cd geocrop-engine
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[all,web]"
.\.venv\Scripts\geocrop.exe demo --root outputs\my-first-demo --quick

# Workspace: first set $env:GEOCROP_WEB_TOKEN (32+ random characters)
.\.venv\Scripts\geocrop.exe serve --workspace . --port 8765
